# Issue 02: Страница управления в AdminPanel (`aiProductCharacteristics.vue`)

## Проблема
Оператору требуется наглядный инструмент в админ-панели для генерации, визуального сопоставления (Было / Стало), точечной ревизии с комментариями и сохранения характеристик товаров по категориям.

## Требования к реализации
1. Создать компонент `app/pages/admin/cms/aiProductCharacteristics.vue`.
2. Компоненты интерфейса:
   - Шапка: иерархический выбор категории (`useCats()`).
   - Таблица/список товаров выбранной категории:
     - Чекбоксы выбора позиций.
     - Индикаторы наличия ТТХ и статуса генерации (`PASS`, `FAIL`, `В процессе`).
     - Кнопка «Сгенерировать характеристики» с прогресс-баром последовательной обработки товаров.
   - Рабочая область выбранного товара:
     - Сплит-режим сравнения: Действующие характеристики (Было) vs Сгенерированные (Стало).
     - Блок вердикта арбитра: статус `PASS` / `FAIL`, критика и замечания.
     - Блок ревизии: текстовое поле замечаний редактора + кнопка «Перегенерировать товар».
   - Сохранение:
     - Сохранение выбранного товара или всех успешных (`PASS`) товаров через POST `/api/admin/cms/products/updProds`.
3. Взаимодействие с Mastra:
   - Подключение через WebSocket-адаптер `mastraWsAdapter`.
   - Последовательный вызов воркфлоу `product-characteristics` по каждому товару с передачей payload.
