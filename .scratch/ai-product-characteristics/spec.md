# Спецификация: AI Характеристики Товаров (`aiProductCharacteristics`)

## 1. Назначение и контекст

Реализация интерфейса панели администратора (`app/pages/admin/cms/aiProductCharacteristics.vue`) и вспомогательного API (`server/api/ai/productsData/[c_alias].js`) для генерации структурированных технических характеристик (`characteristics`) товаров выбранной категории каталога измерительного инструмента.

Генерация выполняется через воркфлоу Mastra (`product-characteristics`) на основе:
- Официальных нормативных документов (ГОСТ, ТУ, Госреестр СИ), привязанных к товару;
- Действующих характеристик товара из базы данных (`i_products.characteristics`);
- Характеристик категории (строго для товаров без документов в качестве контекста);
- Ресерча по товару через Tavily (для товаров без документов).

---

## 2. Архитектура решения

1. **API выборки данных (`server/api/ai/productsData/[c_alias].js`)**:
   - Принимает `c_alias` категории (корневой или подкатегории).
   - Возвращает агрегированные данные:
     - `category`: метаданные категории и ее `characteristics`.
     - `docs`: словарь документов (`stnd`, `rstr`) с полными распарсенными текстами Markdown.
     - `products`: массив товаров категории со свойствами, текущими ТТХ и массивами привязанных ID документов (`stndIds`, `rstrIds`).
2. **UI страницы (`app/pages/admin/cms/aiProductCharacteristics.vue`)**:
   - Иерархический выбор категории (`useCats()`).
   - Таблица товаров с индикаторами наличия ТТХ и статусов генерации (`PASS`, `FAIL`, `В процессе`).
   - Кнопка «Сгенерировать характеристики» с последовательной обработкой товаров через `mastraWsAdapter`.
   - Карточка выбранного товара: сплит-просмотр «Было / Стало», замечания арбитра.
   - Поле ввода замечаний редактора + кнопка «Перегенерировать товар» (ревизия).
   - Кнопки сохранения: сохранение выбранного товара или массовое сохранение успешных (`PASS`) в `server/api/admin/cms/products/updProds.js`.
