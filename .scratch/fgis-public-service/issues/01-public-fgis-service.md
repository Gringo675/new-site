# Issue 01: Публичный сервис поиска по ФГИС ГРСИ с витриной товаров

Status: resolved
Type: task

## Описание
Создать общедоступную страницу `/materials/fgis` для поиска по Государственному реестру средств измерений (ФГИС «АРШИН») Росстандарта с маркетинговой интеграцией каталога товаров.

## Согласованные решения
- **URL**: `/materials/fgis.vue` (существующие страницы не затрагиваются).
- **Интерфейс**: Split View на десктопе (реестр слева, витрина справа) + выезжающая снизу шторка (Bottom Sheet) на мобильных экранах.
- **Пагинация**: По образцу `app/pages/admin/log.vue:617-641` — выбор количества строк (20, 50, 100) через `USelect`, компонент `UPagination` и строка диапазона `Показано {pageRangeText}`.
- **Стартовый экран**: Поисковый блок по центру с кликабельными подсказками (Search-first).
- **Синхронизация URL**: Поддержка query-параметров (`?number=...`) для шаринга ссылок и прямого входа.
- **Отдача PDF**: Прямое потоковое проксирование файлов из ФГИС через `/api/fgis/file/[uuid]` с открытием во вкладке браузера.
- **Оптимизация производительности**:
  1. Стартовая загрузка компактной карты наших номеров ГРСИ (`/api/fgis/numbers`) со счётчиком товаров.
  2. Быстрый поиск в Solr без JOIN (`/api/fgis/search`).
  3. Мгновенная сверка на клиенте и маркировка бейджами («N в наличии»).
  4. Ленивая подгрузка товаров (`/api/fgis/products?number=...`) только при клике на конкретный прибор.
  5. Быстрое добавление в корзину через `addProductToCart`.
