# Сортировка результатов поиска в Госреестре СИ (ФГИС «АРШИН»)

Status: closed
Type: task

## Согласованная спецификация (по результатам /grill-me и доработки UI)

### 1. Место размещения в интерфейсе
- В шапке списка результатов (`List Header` в `app/pages/materials/fgis.vue`), вместо фраз «Выберите строку для просмотра справа» (десктоп) и «Нажмите для просмотра товаров» (мобайл).
- Текстовая подпись «Сортировка:» убрана для компактности и предотвращения сдвига.
- Доступно как на десктопе, так и на мобильных устройствах (`< 1024px`).

### 2. Состав элементов управления
- **Кнопка направления (`UButton`, `size="xs"`, `variant="outline"`)**:
  - Расположена слева от селектора.
  - Всегда присутствует в разметке; при активном пункте «По релевантности» переводится в неактивное состояние (`:disabled="sortField === 'relevance'"`), исключая сдвиг дропбокса.
  - При выборе других полей становится активной и переключает `asc` (По возрастанию) / `desc` (По убыванию) в 1 клик.
  - Иконки: `i-lucide-arrow-up-narrow-wide` / `i-lucide-arrow-down-wide-narrow`.
- **Селект критерия (`USelect`, `size="xs"`)**:
  - `По релевантности` (value: `'relevance'`) — значение по умолчанию
  - `По номеру` (value: `'number'`)
  - `По наименованию` (value: `'name'`)
  - `По обозначению` (value: `'type_si'`)
  - `По производителю` (value: `'brand'`)
  - `По сроку действия` (value: `'date'`)

### 3. Алгоритмы сортировки
- `relevance`: исходный порядок выдачи Solr из ФГИС.
- `number`: лексикографическая строковая сортировка по тексту номера `a.number.localeCompare(b.number)`.
- `name`: алфавитная сортировка `(a.name || '').localeCompare(b.name || '', 'ru')`.
- `type_si`: алфавитная сортировка по обозначению типа `(a.type_si || '').localeCompare(b.type_si || '', 'ru')`.
- `brand`: алфавитная сортировка по производителю `(a.brand || '').localeCompare(b.brand || '', 'ru')`.
- `date`: по дате действия `new Date(a.date).getTime() || 0` (записи без даты — в конец).
- Направление `asc` / `desc` инвертирует результат.
- Сортировка строгая по выбранному полю (для отбора наличия используется фильтр «Только товары в наличии»).

### 4. Поведение при переключении
- Сброс пагинации на 1 страницу (`page.value = 1`).
- На десктопе автоматический выбор первой карточки в новом порядке: `handleSelectDoc(paginatedDocs.value[0], false)`.
- При новом поиске или сбросе: сброс на «По релевантности».
