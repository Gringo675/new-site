# Спецификация: Публичный сервис ФГИС ГРСИ (/materials/fgis)

## Контекст и цели
Создание общедоступного веб-сервиса на базе официального реестра ФГИС «АРШИН» (Росстандарт) по адресу `/materials/fgis`.
Сервис выступает удобным и быстрым интерфейсом (прокси) для поиска описаний типов средств измерений и методик поверки, а также выполняет маркетинговую функцию:
- Автоматически связывает найденные записи ГРСИ с товарами в каталоге компании.
- Позволяет посетителю прямо из результатов поиска увидеть подходящие поверенные инструменты в наличии и оформить заказ / перейти в карточку товара.

## Архитектурные решения
1. **URL страницы**: `/materials/fgis` (отдельная страница, существующие компоненты и маршруты не затрагиваются).
2. **Публичный прокси**: публичный эндпоинт `/api/fgis/search`, не требующий авторизации администратора.
3. **Оптимизация производительности**:
   - При загрузке страницы один раз подгружается компактная карта номеров ГРСИ из `i_docs_rstr` (`/api/fgis/numbers`), включая счётчики привязанных товаров (`{ "20448-00": 3, ... }`).
   - Поисковый запрос во ФГИС выполняется без тяжёлых JOIN с БД.
   - Сверка найденных результатов с локальной базой происходит мгновенно на клиенте через `O(1)` Map/Set.
   - Детальный список товаров (`/api/fgis/products?number=...`) запрашивается лениво (lazy) **только при активации/клике на конкретную запись реестра**.
4. **Прототипы интерфейса**: интерактивный прототип с тремя вариантами представления создан в `.scratch/fgis-public-service/prototype.html`.

## Варианты интерфейса (в прототипе)
1. **Вариант 1 (Инлайн-аккордеон)**: Таблица реестра, где строки с товарами имеют бейдж и раскрываются вниз с карточками товаров.
2. **Вариант 2 (Split View / Master-Detail — Выбранный базовый)**:
   - **На десктопе**: Реестр СИ слева (7 колонок), фиксированная панель деталей СИ + официальных PDF + витрины товаров справа (5 колонок).
   - **Пагинация (референс `app/pages/admin/log.vue:617-641`)**:
     - Блок управления под таблицей: `Показано {start}–{end} из {total}`.
     - Селектор строк `USelect` (20, 50, 100 строк).
     - Компонент `UPagination` (`v-model:page="page"`, `:items-per-page="pageSize"`, `:total="total"`).
   - **На мобильных (адаптив)**:
     - *Режим 2A (Выбранный)*: **Нижняя шторка (Bottom Sheet / Drawer)** — при клике на строку снизу экрана выезжает модальная шторка с деталями и товарами.
3. **Вариант 3 (Умные карточки)**: Карточки инструментов с быстрыми фильтрами и промо-блоком покупки в наличии.
