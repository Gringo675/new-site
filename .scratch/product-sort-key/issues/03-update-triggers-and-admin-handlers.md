# 03 - Automatic `sort_key` Update Triggers in Product Handlers

## Описание
Встроить автоматический пересчет и сохранение поля `sort_key` во все обработчики, где создаются или изменяются товары и их характеристики, а также при изменении порядка свойств в админке.

## Требования

1. **Редактирование товаров в админке (`server/api/admin/cms/products/updProds.js`):**
   - При получении новых значений параметров (`p0_brand` .. `p8_pack`) перед сохранением вычислять новый `sort_key`.
   - Включать `sort_key` в SQL `UPDATE i_products`.

2. **Импорт товаров (`server/api/admin/dbImport/products.js`):**
   - При создании новых товаров или массовом обновлении вычислять `sort_key` перед пакетной вставкой/обновлением.

3. **Синхронизация через Excel / внешние API:**
   - Если в `server/api/excel/update-products.post.js` или `server/api/1c/products.post.js` передаются характеристики, проверять необходимость обновления `sort_key`.

4. **Изменение порядка свойств в админке (`server/api/admin/setProperties.js`):**
   - Если администратор меняет значение поля `ordering` для какого-либо свойства в таблице `i_properties`, найти все товары, у которых в соответствующих полях `p0`..`p8` используется данный `prop_id`.
   - Запустить для найденных товаров фоновый пересчет `sort_key`.

## Критерии приемки
- [ ] При изменении любой характеристики товара через админку его `sort_key` сразу обновляется в БД.
- [ ] При импорте новых товаров поле `sort_key` заполняется автоматически.
- [ ] При изменении `ordering` свойства в справочнике `i_properties` зависимые товары обновляют свои ключи.
- [ ] Нет рассинхронизации между характеристиками товара и его `sort_key`.
