# 05 - Production (Cloud) DB Schema Update & Migration

## Описание
После успешной реализации, локального тестирования и валидации нового функционала в среде разработки, применить изменения схемы и пересчет `sort_key` на боевой облачной базе данных (хостинг Beget, база `chelin_v2`).

## Требования

1. **Подготовка и бэкап:**
   - Перед внесением изменений структуры на проде убедиться в наличии актуального дампа таблицы `i_products`.

2. **Изменение структуры боевой БД:**
   - Выполнить DDL-запросы на облачной базе:
     ```sql
     ALTER TABLE i_products ADD COLUMN sort_key VARCHAR(64) NOT NULL DEFAULT '';
     ALTER TABLE i_products ADD INDEX idx_cat_sort (category_id, sort_key);
     ```

3. **Миграция данных на проде:**
   - Запустить миграционный скрипт расчета `sort_key` для всех товаров в облачной базе данных.
   - Проверить, что 100% опубликованных товаров получили валидный 51-символьный ключ.

4. **Верификация боевого сайта:**
   - Проверить порядок товаров на основных страницах категорий на продакшене.
   - Проверить работу фильтров и админки.

## Критерии приемки
- [ ] В облачной базе `chelin_v2` добавлена колонка `sort_key` и индекс `idx_cat_sort`.
- [ ] Все товары на проде имеют рассчитанные значения `sort_key`.
- [ ] Проверено отсутствие пустых или поврежденных ключей.
- [ ] Каталог на продакшене отображается упорядоченным по ГОСТ без ошибок.
