# AGENTS.md

## Project Overview

This is a Nuxt v4 e-commerce website built with:
- Frontend: Nuxt v4, Nuxt UI v4, TailwindCSS v4, Vue 3 Composition API
- Backend: Node.js, MySQL

## Rules

- Do not run `npm run build` or `npm run dev`.
- Create git commits only after explicit user approval.

## Agent skills

### Issue tracker

Issues live as local markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses default triage status labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repo using `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.
