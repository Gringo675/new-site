# Как выбрать штангенциркуль?

**Штангенциркуль** — самый универсальный и распространенный измерительный инструмент. Он позволяет измерять линейные наружные и внутренние размеры длиной до 4 метров с точностью до 0,01 мм.

В конструкции всех штангенциркулей есть общие элементы — они состоят из штанги, соединенной с неподвижной губкой, на которую одевается рамка с подвижной губкой. На штангу нанесена измерительная штриховая шкала. Сверху на рамке устанавливается стопорный винт для закрепления размера.

## Типы штангенциркулей по способу снятия показаний

1. **Нониусные штангенциркули (тип ШЦ)** — классический тип, отсчет производится по штриховой шкале нониуса. Точность измерений: 0,1 мм, 0,05 мм и 0,02 мм.
2. **Цифровые электронные штангенциркули (тип ШЦЦ)** — отсчет по жидкокристаллическому дисплею. Точность: 0,01 мм. Возможности: установка нуля в любой точке, переключение мм/дюймы, вывод данных на ПК.
3. **Стрелочные штангенциркули с круговой шкалой (тип ШЦС / ШЦК)** — для снятия показаний используется стрелочный индикатор часового типа. Точность: 0,02 мм и 0,01 мм.

## Типы штангенциркулей по конструкции (ГОСТ 166-89)

- **Тип ШЦ-I:** двусторонние с измерительными верхними и нижними губками и выдвижным глубиномером (называемый «колумбус»). Длина штанги: 125, 150, 200, 250, 300 мм.
- **Тип ШЦ-II:** двусторонние с верхними разметочными (острозаточенными) и нижними измерительными губками. Служат для разметки и измерения наружных/внутренних размеров. Выпускаются длиной до 2000 мм.
- **Тип ШЦ-III:** односторонние только с нижними губками. Служат для измерения средних и больших размеров (до 4000 мм).

## Специальные типы штангенциркулей

- **ШЦР, ШЦСР (разметочные):** для разметки деталей на твердых поверхностях с твердосплавными губками (0–150, 0–200, 0–300, 0–500 мм).
- **Для внутренних / наружных канавок:** губки специальной ступенчатой формы для измерения пазов и выточек.
- **Для стенок труб:** неподвижная губка цилиндрической формы для измерения изогнутых поверхностей.
- **Для измерения уступов:** подвижная переставляемая по высоте губка для ступенчатых деталей.

## Длина губок и материалы

- Стандартная длина губок: от 40 мм (для 125–150 мм) до 125 мм (для штанг 1000–2000 мм).
- Удлиненные губки (типы ШЦ-II и ШЦ-III): 90, 100, 125, 150, 200, 250, 300 мм.
- Материал: инструментальная углеродистая или нержавеющая сталь с закалкой до 60 HRC, либо твердосплавные напайки (**тип ШЦТ**) для абразивных и высокопрочных условий.
