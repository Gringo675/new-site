# Поиск по Государственному реестру средств измерений (ФГИС РСТ / ГРСИ)

Сервис онлайн-поиска по Федеральному информационному фонду по обеспечению единства измерений (ФГИС РСТ Росстандарта), предоставляемый ООО ТД «Челябинский Инструмент».

## Назначение сервиса
Сервис позволяет оперативно находить утвержденные типы средств измерений (СИ), проверять их регистрационный номер в ГРСИ, срок действия свидетельства об утверждении типа, а также скачивать официальную нормативно-техническую документацию.

## Государственный реестр средств измерений (ГРСИ)
Государственный реестр СИ ведется Федеральным агентством по техническому регулированию и метрологии (Росстандарт) в соответствии с Федеральным законом от 26.06.2008 № 102-ФЗ «Об обеспечении единства измерений». Внесение типа СИ в ГРСИ подтверждает, что прибор прошел государственные метрологические испытания и допущен к применению в сфере государственного регулирования обеспечения единства измерений (в промышленности, строительстве, энергетике, торговле и на опасных производственных объектах).

## Сведения в реестре ФГИС РСТ
В реестре содержатся сведения об утвержденных типах средств измерений: регистрационный номер, наименование типа, предприятие-изготовитель, интервал между поверками, а также официальные Описания типа и Методики поверки.

## Документы, доступные для скачивания
- **Описание типа (ОТ)** — официальный документ Росстандарта, содержащий метрологические и технические характеристики типа прибора (диапазон измерений, пределы допускаемой погрешности, условия эксплуатации, комплектность, межповерочный интервал).
- **Методика поверки (МП / МИ)** — документ, регламентирующий методы, средства, условия и алгоритм проведения первичной и периодической поверки средства измерений.

## Возможности поиска в сервисе
- Поиск по номеру ГРСИ (например, 72189-18, 9289-83, 39286-08).
- Поиск по наименованию средства измерений (штангенциркули, микрометры, индикаторы, нутромеры).
- Поиск по обозначению типа СИ (ШЦ-I, МК, ИЧ).
- Поиск по предприятию-изготовителю или стране производства (ЧИЗ, КРИН, СТИЗ, Mitutoyo, Mahr).

## Подбор и поставка поверенного инструмента
Сервис автоматически сопоставляет найденные номера Госреестра с актуальным каталогом продукции ООО ТД «Челябинский Инструмент». Если найденный тип СИ есть в ассортименте компании, пользователь видит соответствующие товары с ценами, фотографиями и возможностью быстрого заказа инструмента с первичной поверкой аккредитованной метрологической лаборатории.
